## 🧠 About This Directory

Welcome to the **NEXUS Source Code Center**.

This directory contains the main software files of NEXUS Vision Engine, an AI-powered computer vision platform developed using Python and YOLO.

It brings together the application's core implementation and supporting resources in an organized software structure.

## 📂 Project Files

| File | Description |
|---|---|
| `NEXUS_Vision_Engine_Bilingual_Final.py` | Main Python application and bilingual graphical interface. |
| `NEXUS_Vision_Engine_Video_Studio.txt` | Supporting text resource related to the Video Studio component. |
| `README.md` | Source code documentation and usage guide. |

## 🛠️ Technology Stack

- 🐍 **Python** — Core programming language.
- 🤖 **YOLO** — AI-based visual recognition technology.
- 🖥️ **GUI** — Graphical user interface.
- 🌐 **Bilingual Support** — Arabic and English interface.

## 🚀 Getting Started

Run the following commands from the main project directory.

**1. Install Dependencies**

```bash
pip install -r requirements.txt
```

**2. Launch the Application**

```bash
python src/NEXUS_Vision_Engine_Bilingual_Final.py
```
