## 01. About the Project

**NEXUS Vision Engine** is an AI-powered computer vision platform designed to transform visual data into meaningful information through intelligent image and video analysis.

Developed using Python and YOLO, the system brings together artificial intelligence, computer vision, and software engineering in an integrated application with a modern graphical user interface.

The project aims to provide an accessible and interactive environment for exploring intelligent visual processing, analyzing visual content, and demonstrating the practical capabilities of AI-driven vision systems.

NEXUS represents an engineering approach to building intelligent software systems that connect advanced algorithms with practical applications.

## 02. Core Capabilities

- **Object Detection:** Identifying and locating objects within visual content.
- **Image Analysis:** Processing and analyzing digital images using computer vision techniques.
- **Video Analysis:** Applying AI-based visual analysis to video content.
- **Object Segmentation:** Separating objects and identifying their regions within images.
- **Real-Time Tracking:** Following detected objects across video frames.
- **Graphical User Interface:** An interactive environment for accessing the system's features.
- **Bilingual Interface:** Supporting Arabic and English interaction.

## 05. Installation & Setup

**Prerequisites**

- Python 3.10 or later.
- A compatible operating system.
- Required Python dependencies.

**Step 1 — Clone the Repository**

```bash
git clone https://github.com/sadahmedm45-hue/NEXUS-Vision-Engine.git
```

**Step 2 — Navigate to the Project Directory**

```bash
cd NEXUS-Vision-Engine
```

**Step 3 — Install Dependencies**

```bash
pip install -r requirements.txt
```

**Step 4 — Run the Application**

```bash
python src/NEXUS_Vision_Engine_Bilingual_Final.py
```
